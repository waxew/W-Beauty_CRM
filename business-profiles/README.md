# Business Profiles

این پوشه برای اطلاعات مستقل هر کسب و کار استفاده می شود.

هر محصول فقط یک Profile فعال دارد و Core CRM نباید وابستگی مستقیم به برند یا صنف داشته باشد.

نمونه Profile ها:

- beauty_salon_01
- facial_center_03
- mobile_store_02

اطلاعات قابل تغییر:

- نام کسب و کار
- شناسه محصول
- لوگو و تصاویر
- رنگ سازمانی
- متن ها
- قابلیت های فعال

تغییر Profile نباید نیازمند تغییر منطق Core CRM باشد.
