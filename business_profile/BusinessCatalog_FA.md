# کاتالوگ فارسی Business Profile

## هدف
این فایل مرجع کسب و کارهای پشتیبانی شده در معماری Business Profile است.
Core نباید وابسته به صنعت خاص باشد و هر کسب و کار فقط از طریق Profile تعریف می‌شود.

## قوانین

- Module دارای منطق و Workflow است.
- Attribute Schema فقط داده متغیر است.
- هیچ فیلد اختصاصی صنعت نباید وارد Core Entity شود.
