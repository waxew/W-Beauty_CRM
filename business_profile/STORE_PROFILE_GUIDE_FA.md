# راهنمای Business Profile فروشگاهی

## هدف

Business Profile مشخص می‌کند یک نسخه از نرم افزار برای چه کسب و کاری اجرا شود.

## قوانین

- Core نباید شامل منطق یک صنف خاص باشد.
- Module ها دارای Workflow و منطق هستند.
- Attribute Schema فقط داده‌های متغیر را نگهداری می‌کند.

## شناسه‌ها

فرمت پیشنهادی:

`business_type_001`

مثال:

`mobile_store_001`

## کسب و کارهای تعریف شده

- mobile_store_001
- boutique_store_001
- cosmetics_store_001
- home_appliance_store_001
- auto_parts_store_001
- jewelry_store_001
- book_store_001
- grocery_store_001
- pet_store_001
- omnichannel_store_001
