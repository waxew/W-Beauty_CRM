# راهنمای فارسی Business Profile

## Business Profile چیست؟
لایه تنظیمات یک CRM برای ساخت نسخه‌های مختلف از یک Core مشترک است.

## افزودن کسب‌وکار جدید
1. یک Profile جدید بسازید.
2. شناسه یکتا تعریف کنید.
3. Module های مورد نیاز را فعال کنید.
4. Attribute Schema های اختصاصی را اضافه کنید.

## قوانین
- Industry نباید داخل Core نوشته شود.
- Attribute نباید Field ثابت Entity باشد.
- Module شامل منطق و Workflow است.
- Attribute Schema فقط داده توصیفی است.
